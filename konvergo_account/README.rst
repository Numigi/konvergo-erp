Konvergo / Accounting
=====================
Module that installs accounting modules required for Konvergo.

The module is a based on `Numipack Accounting <https://github.com/Numigi/odoo-base/tree/14.0/numipack_account>`_
and `Konvergo <https://github.com/Numigi/odoo-base/tree/14.0/konvergo_base>`_
